# EPUB Reader Dictionary Packs

Open-licensed offline dictionary packages for the EPUB Workspace reader.

The application reads `catalog.json`, downloads only the package selected by the user, verifies its size and SHA-256 digest, then validates the package-internal checksums and SQLite schema before installation.

Each archive contains its own `LICENSE.txt`, `ATTRIBUTION.txt`, and `SOURCE.txt`. Content licenses apply per package; repository metadata and packaging scripts do not replace those licenses.
